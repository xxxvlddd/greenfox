## Установка

Нужен Mac на Apple Silicon (M1 и новее) и macOS 12 Monterey или новее.

**Одной командой** — откройте «Терминал» и вставьте:

```sh
curl -fsSL https://raw.githubusercontent.com/xxxvlddd/greenfox/main/scripts/install.sh | bash
```

Скрипт скачает последнюю версию со страницы релизов, сверит контрольную
сумму и положит GREENFOX в «Программы». Что именно он делает, можно
прочитать до запуска: [scripts/install.sh](scripts/install.sh).

**Через Homebrew:**

```sh
brew install --cask xxxvlddd/tap/greenfox
```

**Вручную:** скачайте `GREENFOX-arm64.dmg` со страницы
[Releases](https://github.com/xxxvlddd/greenfox/releases/latest), откройте его и
перетащите GREENFOX в «Программы».

### Если macOS не даёт открыть

У приложения нет платной подписи разработчика Apple. После установки
командой или через Homebrew предупреждения не будет. Если `.dmg` скачан
браузером, при первом запуске macOS скажет, что не может проверить
разработчика. Тогда: «Системные настройки» → «Конфиденциальность и
безопасность» → внизу «Всё равно открыть». Или одной командой:

```sh
xattr -dr com.apple.quarantine /Applications/GREENFOX.app
```

### Обновление

GREENFOX обновляется сам. Раз в сутки он спрашивает у GitHub, вышла ли
новая версия, и если вышла — показывает в углу плашку с кнопкой «Обновить».
Ставится только версия, подписанная ключом автора: подпись, размер и
контрольная сумма проверяются до установки. Учёт не трогается, перед
заменой делается копия базы. Выключить проверку — «Настройки» → «О
программе» → «Обновления».

Можно и вручную: та же команда установки ещё раз — или
`brew upgrade --cask greenfox`.

### Удаление

`brew uninstall --cask greenfox` или перетащите GREENFOX из «Программ» в
корзину. Сам учёт останется в `~/Library/Application Support/GREENFOX` —
удалите эту папку, если хотите стереть и его (через Homebrew то же самое
делает `brew uninstall --zap --cask greenfox`).

## Что умеет

- **Обзор** — сколько денег на повседневных счетах, сколько можно тратить в день
  до следующего поступления, на сколько хватит денег при разном темпе трат.
- **Расходы** — траты по категориям за любой период, крупные и необычные
  траты, журнал операций с поиском.
- **Капитал и долги** — чистый капитал, кредит и кредитная карта с условием
  льготного периода, сверка с банком.
- **Прогнозы, планы покупок, календарь, обязательные платежи.**
- **Счета в рублях, долларах и евро** — пересчёт по курсу ЦБ РФ на нужный день.
- **Ассистент** (по желанию) — отвечает на вопросы о ваших деньгах и разбирает
  записи вида «вчера 1200 в пятёрочке» в операции. Работает через
  [OpenRouter](https://openrouter.ai) с вашим ключом.
- Мастер первого запуска, горячие клавиши, автоматические копии базы,
  выгрузка и загрузка таблиц CSV, светлая и тёмная тема.

## Данные и приватность

- Учёт хранится в одном файле базы SQLite на вашем Mac:
  `~/Library/Application Support/GREENFOX/data/finances.db`. Копии базы
  делаются сами.
- В интернет приложение обращается только в двух случаях:
  - к **OpenRouter** — если вы сами добавили ключ ассистента: уходит вопрос и
    данные, нужные для ответа;
  - к **сайту ЦБ РФ** — если есть счёт в долларах или евро: уходят только даты
    и код валюты;
  - к **GitHub** — раз в сутки узнать, вышла ли новая версия (выключается в
    настройках): в запросе нет ничего о вас и вашем учёте.
- Нет аккаунтов и статистики.
- Ключ ассистента хранится шифром через связку ключей macOS.

Как всё устроено внутри — [ARCHITECTURE.md](ARCHITECTURE.md). Что менялось —
[CHANGELOG.md](CHANGELOG.md).

## Сборка из исходников

Нужны Node.js 22 или новее и npm.

```sh
git clone https://github.com/xxxvlddd/greenfox.git
cd greenfox
npm install
npm start        # запустить без сборки
npm run dist     # собрать release/greenfox-<версия>-arm64.dmg
```
